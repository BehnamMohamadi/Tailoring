# مزون بیتا — خیاطی و پنل درخواست تماس

فرانت‌اند: HTML، CSS و JavaScript خام. بک‌اند: Express. دیتابیس: SQLite داخلی Node.js.

رابط جدید در `public/bita.css`، `public/bita.js` و `public/models-data.js` قرار دارد. صفحات: خانه، مدل‌خانه، جزئیات مدل، دوخت زنانه، تعمیرات، درباره بیتا، درخواست تماس و حریم خصوصی.

دوخت فقط لباس ساده زنانه است؛ خدمات مردانه محدود به تعمیرات است. خیاط اصلی آقا و مسئول اندازه‌گیری بانوان خانم است. انتخاب رنگ حذف شده و انتخاب دسته مستقیم مدل‌های مرتبط را نمایش می‌دهد. پسندیده‌ها در مرورگر و درخواست تماس در SQLite ذخیره می‌شوند.

پشتیبان رابط پیشین در `../output/backup-before-bita` است.

## اجرای محلی

به Node.js نسخه ۲۴ یا بالاتر نیاز دارد.

```powershell
npm install
node scripts/setup.mjs
npm start
```

سایت: http://127.0.0.1:3000

مدیریت: http://127.0.0.1:3000/admin.html#/admin

رمز تصادفی اولیه در فایل محلی `.admin-access.txt` و تنظیم `ADMIN_PASSWORD` در `.env` قرار دارد. این فایل‌ها در Git ذخیره نمی‌شوند. اطلاعات واقعی درخواست‌ها در `data/atelier.sqlite` ذخیره می‌شود؛ پوشه data را عمومی نکنید.

## قابلیت‌ها

- صفحه اصلی، دوخت زنانه، مدل‌خانه قابل جست‌وجو و فیلتر، جزئیات مدل، تعمیرات، درخواست تماس، درباره بیتا و حریم خصوصی.
- دریافت نام، موبایل ایرانی، موضوع و توضیح اختیاری؛ اعتبارسنجی در مرورگر و سرور، پشتیبانی از ارقام فارسی و عربی.
- ذخیره واقعی درخواست‌ها؛ جلوگیری از ثبت مجدد همان شماره و موضوع در یک دقیقه.
- مدیریت رمزدار، شماره قابل تماس، تغییر وضعیت، جست‌وجو، فیلتر، خروجی CSV و حذف با تأیید.
- کوکی HttpOnly، محافظت CSRF برای مدیریت، محدودیت تلاش ورود و ثبت درخواست، ذخیره هش توکن جلسه.
- بدون React، کتابخانه UI، ابزار build، پرداخت یا آپلود فایل.

تصاویر مدل‌خانه تولیدشده با هوش مصنوعی و نمونه‌های نمایشی‌اند، نه نمونه‌کار واقعی. فونت Vazirmatn با مجوز OFL در assets قرار دارد.

## انتشار واقعی

به یک هاست Node.js با دیسک پایدار نیاز است. **Sites میزبان Express نیست**؛ این پروژه را روی هاست Node یا VPS اجرا کنید. SQLite برای یک نمونه برنامه و حجم معمول یک آتلیه مناسب است؛ روی هاست بدون دیسک پایدار، اطلاعات از بین می‌رود. برای چند سرور به دیتابیس مشترک نیاز است.

1. `npm ci --omit=dev` را اجرا کنید.
2. رمز قوی و اختصاصی برای `ADMIN_PASSWORD` تنظیم کنید.
3. `NODE_ENV=production`، `HOST=0.0.0.0`، `PORT` مناسب و `PUBLIC_ORIGIN` برابر مبدأ دقیق HTTPS دامنه تنظیم کنید.
4. HTTPS را در reverse proxy فعال کنید. فقط در صورت داشتن دقیقاً یک پراکسی قابل اعتماد، `TRUST_PROXY=1` قرار دهید؛ پورت برنامه را مستقیماً از اینترنت باز نکنید.
5. فرایند را با مدیر سرویس اجرا کنید و از SQLite به روش سازگار با WAL نسخه پشتیبان بگیرید. فایل‌های DB، WAL و SHM را هنگام اجرای برنامه جداگانه کپی نکنید؛ از SQLite backup استفاده کنید.
6. تصاویر و متن معرفی را با اطلاعات واقعی آتلیه جایگزین کنید. صفحه مدیریت تنها با رمز قوی قابل دسترسی باشد.

بک‌اند صرفاً درخواست تماس ذخیره می‌کند؛ زمان مشخصی برای تماس یا رزرو قطعی به مشتری وعده نمی‌دهد. نرخ‌محدودسازی در حافظه همان سرور است و با راه‌اندازی مجدد صفر می‌شود؛ در استقرار چندنمونه‌ای به ذخیره مشترک نیاز دارد.
